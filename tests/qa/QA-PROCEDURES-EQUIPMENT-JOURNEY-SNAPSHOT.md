# QA Procedure Equipment Journey Snapshot

Ejecute `npm run test:equipment-journey-snapshot` contra un ambiente aislado. La prueba crea el caso solo mediante interfaz y captura el snapshot tras recepción, técnica, comercial y logística.

Se aprueba si no cambia `recordId`, `itemId`, serie, dueño o técnico entre etapas, y si la remisión se abre con la OC, NIT y accesorios ya diligenciados.
